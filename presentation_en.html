Challenges in Automated UI Generation

Traditional MDE Bottlenecks

  • Rigid Styling: Only basic HTML tables and layouts.
  • Inflexible Patterns: No automatic adaptation to business semantics.
  • High Maintenance: Style changes require manual template rewrites.

AI Integration Hurdles

  • Hallucinations: AI invents non-existent UUIDs/Attribute IDs.
  • Aesthetic Drift: Inconsistent CSS classes across generations.
  • Logic Gaps: UI decoupling from core UML business models.

Core Innovation: 4-Agent Pipeline

Transitioning from "Raw Code Generation" to "Semantic JSON Filling"

Strategist

Intent Analysis

Translates natural language into a structured execution plan.

Architect

Structure Builder

Determines screen types (Wizard/Grid) and binds UML IDs.

Stylist

Visual Expert

Manages 18 Semantic Tokens to map intent to Tailwind classes.

Validator

Logic Guard

Eliminates hallucinations and ensures 100% UML compliance.

The 18-Token Semantic Schema

Tier 1: Page (Layout)
page.body.bgpage.body.textpage.container.max_width
Tier 2: Component (Containers)
component.card.bgcomponent.card.shadowcomponent.nav.active
Tier 3: Element (Interactive)
element.button.primaryelement.input.borderelement.text.accent

Ensures 1:1 visual parity between Designer Previews and Production Prototypes.

Security & Reliability: Self-Healing Logic

Hallucinated ID: "uuid-unknown"
➔
Validator heals to: "original_entity_id"
