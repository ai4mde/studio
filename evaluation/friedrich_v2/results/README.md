# Result runs

Each child directory is one immutable Friedrich V2 evaluation run. The runner refuses
to overwrite an existing directory. A run contains `candidate_summary.csv`,
`case_summary.csv`, `automatic_items.jsonl`, `human_review.csv`,
`aggregate_summary.json`, and `provenance.json`. Do not manually edit generated files.

No real run exists yet because the generated ActivityGraph cohort is unresolved.
