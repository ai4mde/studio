1. Commit exactly the 278 `MUST_COMMIT` checkout files from `freeze/thesis_final_v8_20261005/branch_file_scope.csv`, plus the complete freeze directory and this `portable_replay_v1` directory. Do not stage the 368 historical guard-only files merely because the old v6 runner referenced them. Retain historical branches and worktrees unchanged.
2. Use Python 3.12.14 on macOS arm64 to reproduce the validated environment exactly. The verifier checks the recorded interpreter SHA-256, platform, and name/version/METADATA hashes for all 44 installed distributions. A portable installation recipe or lockfile for these 44 packages has not yet been created; distribution metadata hashes do not pin every wheel byte. The existing `.venv-friedrich-v2` passes locally.
3. Obtain `sentence-transformers/all-MiniLM-L6-v2` revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41` separately. The ~932 MB model is not bundled. Pass its snapshot directory with `--model-snapshot`. All 30 snapshot file hashes are verified before replay. The wrapper makes a temporary cache link and never downloads a model implicitly.
4. The sibling `studio-semantic-v2` worktree is not required. Its 132 used files are preserved in `studio_semantic_v2_runtime_snapshot.tar.gz`; the omitted Action compatibility taxonomy is preserved in the separately hashed replay addendum. No mutable adjacent worktree is read during replay.
5. Run content verification first. Then run one replay only when desired. The wrapper writes to a new output directory and compares canonical candidate objects and aggregate metrics with the frozen validated results. A raw JSONL hash can differ solely because diagnostic dictionary keys were inserted in a different order.
6. Do not change `combined_candidate_v8.py`, its imported scoring modules, inventories, or frozen evidence to satisfy the replay. A changed hash must fail verification and be investigated as a new version.

The freeze package contains the exact validated source, data, results, and model hashes. A clean thesis-final branch is self-contained for code/data verification once the reviewed commit scope is staged. Full execution additionally needs the external pinned model and an environment matching the recorded packages. Cross-platform bitwise reproduction is not claimed.
